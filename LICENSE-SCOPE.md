# License scope

Author: JoonHo Lee (jlee296@ua.edu)

The code license applies to the author's own replication code. Data and prose have separate terms. This file explains scope; it does not expand any upstream grant.

| Artifact class | Terms |
|---|---|
| Original replication scripts | MIT (`LICENSE`), continuing the v0 replication code license |
| Original guide, author-created calibration outputs, synthetic simulation summaries, and regenerated exhibits | CC BY 4.0 for the author's contribution (`LICENSE-DATA`) |
| STAR/metadat source packages or third-party code | Their own licenses; obtained separately; not relicensed by MIT or CC BY |
| Bootstrap Icons subset used by the guide | Upstream MIT license, retained in `docs/theme/bootstrap-icons-LICENSE.txt`; original glyph outlines are preserved |
| IRW-derived vocabulary summaries | CC BY 4.0 as stated in the IRW derived-license field, subject to underlying rights; attribution and modifications retained |
| OCRS public-use analysis derivatives | Author’s analytical contribution; upstream deposit terms retained; raw files and AIR documentation obtained separately |
| Journal manuscript, original submission files, OCR papers, private logs | Outside the package and outside these grants |

Package metadata can state a software license without establishing a separate license for every original study. We therefore document source access, avoid unnecessary raw-data redistribution, and retain upstream attribution on derived material.
