# Appendix E: Dual-Anchor Calibration Framework

## Figure E05 — Dual-Anchor Pareto Frontier

**Paper location:** Appendix E.5, "Dual-Anchor Calibration Framework"

The Pareto frontier figure is generated by:

```
code/figure_04/figure_04_pareto_frontier.R
```

This script uses the `DPprior` R package to compute trade-off solutions
across a grid of λ values, then plots the resulting Pareto frontier
showing K-fit error vs. dominance risk.

### To reproduce

```bash
cd code/figure_04
Rscript figure_04_pareto_frontier.R
```

Output: `figures/supplement/Figure_E05.{pdf,png,jpg}`
