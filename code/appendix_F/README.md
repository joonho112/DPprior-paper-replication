`data/simulation_results/preprocessed_results.csv`.

`code/figure_03_simulation/analysis/02_figures_generation.py`:

### Supplementary figures (this folder)

These 5 figures require additional computations not covered by the main pipeline
and are generated by `appendix_F_supplementary_figures.R`:

| Paper Figure | Description |
|---|---|
| Figure F02 | Collapse probability P(K=1) — detailed version with 50% reference |
| Figure F04 | Relative MSE improvement over Vague prior (%) heatmap |
| Figure F08 | χ²-DORO comparison (RMSE + collapse, I=0.2 only) |
| Figure F12 | Mode-based recovery: exact P(mode=K*) and near P(\|mode-K*\|≤1) |
| Figure F14 | Bias–variance decomposition of MSE (I=0.2) |

### To reproduce

```bash
# 1. Generate the 9 pipeline figures (requires Python)
cd code/figure_03_simulation/analysis
python 02_figures_generation.py

# 2. Generate the 5 supplementary figures (requires R)
cd code/appendix_F
Rscript appendix_F_supplementary_figures.R
```
