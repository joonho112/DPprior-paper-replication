## LaTeX-Only Tables (no code generation needed)

The following tables are authored directly in LaTeX and do not require
code to reproduce. They can be found in the paper's tex source files:

- **Table 1** (Main Text): Interpretive Functionals for Practitioner Communication
- **Table A1**: Computational complexity of Stirling number computations
- **Tables B1–B3**: Scaling behavior, VIF definitions, approximation errors
- **Tables C1–C2**: Newton correction performance, iteration counts
- **Table D1**: Practical guidelines for informativeness calibration
- **Tables E1–E2**: Dominance risk thresholds, default parameters
- **Tables F1–F4**: Simulation design, fixed parameters, informativeness calibration, prior hyperparameters
- **Tables G1–G6**: DPprior package function mapping, API reference, VIF table, checklist, repository structure

## To Reproduce

```bash
# From the repository root:
cd code/figure_03_simulation/analysis
python 01_data_preparation.py   # Generates preprocessed_results.csv
python 03_tables_generation.py  # Generates all tables above
```

Pre-rendered copies of all tables are included in this directory.
